How it works

  1. 1

    Enter your content

    Paste a link or type a message, or start from a Website, Wi-Fi, Email or Phone template.

  2. 2

    Generate the code

    Select Generate or press Enter. Check the line under the code to see what it contains.

  3. 3

    Download and share

    Save the PNG, then add it to a poster, a menu, a business card or a slide.

Tips for a code that scans

  • Keep it short

    Less content makes bigger squares, which are easier for a camera to read.

  • Print it at 2 cm or larger

    Use a bigger size if people will scan it from a distance.

  • Keep the white margin

    Scanners use the blank border to find the code, so don't crop it.

  • Test before you print

    Scan it with a phone or two first. The code never expires, but a link inside it can stop working.
